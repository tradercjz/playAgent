在DolphinDB中，如何通过函数恢复一个集群下的所有数据库数据，并可以选择保持原名称或重新命名？
Input:
Answer:


在DolphinDB中，可以使用`restoreAllDatabases`函数来恢复一个集群下的所有数据库数据，并通过指定`renameDict`参数实现数据库名称的保留或重命名。具体语法如下：

```sql
restoreAllDatabases(backupDir, renameDict, force=true)
```
参数说明：
- `backupDir`：指定备份目录路径
- `renameDict`：以字典形式指定需要重命名的数据库（格式：旧名称->新名称，不修改名称则不需要包含该键值对）
- `force`：设置为true表示强制覆盖已存在的数据库

示例（保持名称不变）：
```sql
restoreAllDatabases("/hdd/hdd1/backup", force=true)
```

示例（重命名数据库）：
```sql
restoreAllDatabases("/hdd/hdd1/backup", {"originalDB":"newDB"}, force=true)
```
