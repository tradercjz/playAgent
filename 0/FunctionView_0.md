Prompt:
如何让没有读取分布式表权限的用户通过DolphinDB函数视图获取表中数据的计算结果？
Input:
Answer:


要允许没有读取分布式表权限的用户通过函数视图获取数据计算结果，可以按照以下步骤操作：

1. **定义计算逻辑函数**：由管理员创建一个自定义函数（如`getAvg`），在其中封装对目标表的查询和计算逻辑（例如计算每天的平均值）。

2. **封装为函数视图**：使用`addFunctionView`将该函数注册为函数视图：
   ```DolphinDB
   addFunctionView(udf=getAvg)
   ```

3. **授予执行权限**：管理员为用户授予该函数视图的`VIEW_EXEC`权限：
   ```DolphinDB
   grant(userId=`user1, accessType=VIEW_EXEC, objs="getAvg")
   ```

4. **用户调用函数视图**：用户无需直接访问表，通过执行函数视图获取结果：
   ```DolphinDB
   getAvg()
   ```

**关键机制**：函数视图将数据访问权限与计算逻辑解耦，用户仅需函数视图的执行权限，而无需底层表的读取权限。管理员通过封装安全查询逻辑，实现受控的数据访问。
