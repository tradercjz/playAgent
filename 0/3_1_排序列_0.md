Answer:


在DolphinDB TSDB引擎中，创建表时应通过`sortColumns`参数指定排序列，且必须满足以下要求：排序列的最后一个字段必须是时间类型（如TIMESTAMP），其余字段称为排序键。其设计原理是：

1. **时间维度优化**：TSDB引擎针对时间序列场景设计，将时间列作为排序列末位可确保同一排序键下的数据按时间物理有序存储，大幅提升时间范围查询（如`between 09:00:00 and 10:00:00`）的效率。

2. **数据版本管理**：在写入时，系统会按排序列对数据进行排序和去重。时间列作为末位排序依据，可确保同一排序键下的数据按时间戳自然覆盖旧版本，实现隐式的数据去重（如股票行情快照按symbol+time去重）。

3. **存储结构对齐**：TSDB引擎以`排序键+时间区间`作为数据块的物理存储单元，时间列作为末位排序基准可直接映射到存储层的分块策略，减少查询时的磁盘扫描范围。

示例代码：
```python
db = database("dfs://TSDB_demo", VALUE=["AAPL", "MSFT"], engine="TSDB")
t = db.createTable(
    tableName="quotes",
    partitionColumns=["symbol"],
    sortColumns=["symbol", "time"],  # 末位必须是时间类型
    ...
)
```
